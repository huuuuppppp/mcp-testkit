# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **mcp-testkit**, please **do not
open a public GitHub issue**. Instead, report it privately via one of:

- GitHub Security Advisories:
  https://github.com/huuuuppppp/mcp-testkit/security/advisories/new
- Email: `huuuuppppp@users.noreply.github.com` (will be replaced with a
  dedicated security contact once available)

Please include:
- A description of the vulnerability and its impact.
- Steps to reproduce, or a proof of concept.
- The affected version(s).
- Any suggested remediation, if you have one.

## Response Timeline

We aim to:
- Acknowledge reports within **3 business days**.
- Provide an initial assessment and severity rating within **7 business days**.
- Coordinate a fix and embargoed disclosure with the reporter.

## Scope

The following are considered in scope:
- The `mcp-testkit` library, CLI, and published npm package.

Out of scope (please report these to the relevant upstream project instead):
- Vulnerabilities in `@modelcontextprotocol/sdk`, `zod`, or other dependencies.
- Vulnerabilities in the MCP servers you test with this library.
