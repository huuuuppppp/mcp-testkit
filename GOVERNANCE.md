# Governance

## Maintainers

The current sole maintainer is the project author:

- **[@huuuuppppp](https://github.com/huuuuppppp)** — project lead, release
  manager, and final decision-maker.

## Decision-making

The maintainer aims to make decisions transparently, using GitHub issues and
pull requests. Significant changes go through a proposal period so the
community can weigh in before implementation.

As the project grows, long-term contributors who demonstrate sustained,
high-quality involvement may be invited to become maintainers.

## Contribution model

Anyone may open a pull request. Contributions are reviewed by a maintainer,
who may request changes or suggest alternatives before merging. See
[CONTRIBUTING.md](./CONTRIBUTING.md) for details.

## Releases

Only maintainers may publish releases. The process is documented in
[CONTRIBUTING.md](./CONTRIBUTING.md) and automated through GitHub Actions.

## Changes to this document

Material changes to governance are proposed via pull request and merged by a
maintainer after an appropriate comment period.
